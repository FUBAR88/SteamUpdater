PBO packing

        
Templates

      

      

        
        
        
      

      

      
A template packs any number of folders, each into its own PBO, and puts them into the destination. Built-in templates stay as they are. Save as own to change them.

    

    

      

        
Config

        
Built-in template. Pack works as it is. To change paths, packs or keys, save it as your own template.

        

          
          
        

      

      

        
Packs

        
Each folder becomes one PBO, named after the folder. The prefix comes from $PBOPREFIX$ or $PREFIX$ in the folder, else the folder name. Drop folders here to add them.

        

        

          
        

      

      

        
Files and exclusions

        

          
          
A .lst file with one pattern per line, like exclude.lst in DayZ Tools. AddonBuilder always applies its own exclude.lst as well.
